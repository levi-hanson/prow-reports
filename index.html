Help
  1. Sign in with the same ArcGIS account you use for our maps.
  2. Search for the city's results map (for example "Hilton Head Results Map") and pick it.
  3. Optional: untick the maps you don't need (the all-layers map always shows every layer), use ▲▼ to reorder them (top = drawn on top, first in the legend), and change icon sizes (in points; 9 pt is about 1/8 inch). Leave a box blank for the automatic size. Your sizes are remembered for each map in this browser.
  4. Click Generate PDFs and wait for the zip. Each PDF is a single page: the map area is one image and the title, legend and scale bar are sharp text.

The maps use the styling saved in the web map. If something looks off, fix it in the web map and generate again.
