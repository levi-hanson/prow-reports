# PROW Reports

Browser tool for Daxbot's Public Rights-of-Way deliverables: print-ready map PDFs and the full evaluation report, built from an ArcGIS results map after signing in with ArcGIS.

Served with GitHub Pages at https://levi-hanson.github.io/prow-reports/. Source of truth is `~/Downloads/prow-report-web/site` on Levi's Mac; this repo is a published copy.
